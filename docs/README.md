# Skillstead documentation

**English** · [한국어](./README.ko.md)

Start with the document that matches what you are trying to do. You do not need to read the maintainer
references to install or use a skill.

## Use a skill

| Goal | Start here |
| --- | --- |
| Understand what Skillstead offers | [Catalog overview](../README.md) |
| Choose and install one skill | [Installation guide](./INSTALL.md) |
| Create editable technical diagrams | [`svg-infographic`](../skills/svg-infographic/README.md) |
| Check public claims against supplied evidence | [`docs-claim-check`](../skills/docs-claim-check/README.md) |
| Prepare a GitHub repository release safely | [`github-release-guide`](../skills/github-release-guide/README.md) |
| Write, review, revise, or adapt user-facing prose | [`writing-quality-editor`](../skills/writing-quality-editor/README.md) |
| See example outputs and validation material | Browse [`examples/`](../examples/) |

Each skill is a self-contained folder. Its README explains who it is for, what it does, what it does not do,
and how to ask for it. Its `SKILL.md` contains the operating instructions read by the coding agent.

## Maintain the catalog

These references are for people changing Skillstead itself:

| Goal | Reference |
| --- | --- |
| Understand per-skill versions and release impact | [Versioning](./VERSIONING.md) |
| Run repository and release checks | [Validation and release toolchain](./VALIDATION.md) |
| Prepare a public repository release | [Public release playbook](../playbooks/public-release/README.md) |
| Develop, validate, review, release, or retire a skill | [Skill development playbook](../playbooks/skill-development/README.md) |

English documents are canonical. Korean mirrors use the `.ko.md` suffix and preserve the same claims,
conditions, limitations, and required actions in natural Korean.
