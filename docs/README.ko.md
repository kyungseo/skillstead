# Skillstead 문서 안내

[English](./README.md) · **한국어**

하려는 일에 맞는 문서부터 읽으면 됩니다. 스킬을 설치하거나 사용하는 데 유지관리자용 참고 문서까지
읽을 필요는 없습니다.

## 스킬 사용하기

| 하려는 일 | 먼저 읽을 문서 |
| --- | --- |
| Skillstead가 제공하는 스킬 살펴보기 | [카탈로그 소개](../README.ko.md) |
| 스킬 하나를 골라 설치하기 | [설치 안내](./INSTALL.ko.md) |
| 수정 가능한 기술 다이어그램 만들기 | [`svg-infographic`](../skills/svg-infographic/README.ko.md) |
| 공개 문서의 주장을 제공된 근거와 대조하기 | [`docs-claim-check`](../skills/docs-claim-check/README.ko.md) |
| GitHub 저장소 릴리스를 안전하게 준비하기 | [`github-release-guide`](../skills/github-release-guide/README.ko.md) |
| 사용자 문서를 작성·검토·수정하거나 다른 언어에 맞게 다시 쓰기 | [`writing-quality-editor`](../skills/writing-quality-editor/README.ko.md) |
| 결과 예시와 검증 자료 살펴보기 | [`examples/`](../examples/) |

각 스킬은 폴더 하나로 설치할 수 있는 독립 패키지입니다. 스킬별 README에는 적합한 용도, 하는 일과
하지 않는 일, 요청 예시가 들어 있습니다. `SKILL.md`는 코딩 에이전트가 읽는 실행 지침입니다.

## 카탈로그 관리하기

아래 문서는 Skillstead 자체를 변경하는 유지관리자를 위한 참고 자료입니다.

| 하려는 일 | 참고 문서 |
| --- | --- |
| 스킬별 버전과 변경 영향을 이해하기 | [버전 관리](./VERSIONING.ko.md) |
| 저장소 및 릴리스 검사 실행하기 | [검증·릴리스 도구 체계](./VALIDATION.ko.md) |
| 공개 저장소 릴리스 준비하기 | [공개 릴리스 playbook](../playbooks/public-release/README.ko.md) |
| 스킬을 개발·검증·리뷰·릴리스하거나 지원 종료하기 | [스킬 개발 playbook](../playbooks/skill-development/README.ko.md) |

영문 문서가 기준입니다. `.ko.md`로 끝나는 한국어 문서는 같은 주장, 조건, 제한과 필수 행동을
자연스러운 한국어로 전달합니다.
