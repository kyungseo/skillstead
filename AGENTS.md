# Skillstead Agent Entry Point

These instructions apply to maintaining this repository, not to users installing its skills.

Before changing files, read and follow [docs/MAINTAINER-WORKFLOW.md](docs/MAINTAINER-WORKFLOW.md).
Use its current version for documentation alignment, release follow-up, and completion records. Do not rely on
an older conversation or a copied checklist. The owner's current instructions and applicable permissions take
precedence; reuse authorization already granted for the same action and target.

English is canonical for repository documentation; update Korean mirrors when meaning changes. Keep this entry
point thin. Update the workflow and its Korean mirror together when the procedure changes.
