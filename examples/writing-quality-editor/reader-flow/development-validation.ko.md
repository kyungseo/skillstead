# 문단 흐름 개발 검증 — 2026-09-12

[English](./development-validation.md) · **한국어**

`0.15.0` 후보 지침과 공개된 `0.14.1` 지침을 Astra(`gpt-6-astra`, high reasoning effort)로
네 가지 과제에서 비교했습니다. 매 실행은 새 문맥에서 해당 지침을 본문으로 전달받았습니다.
과제마다 기준과 후보를 한 번씩 실행했으며, 순서를 번갈아 배치해 총 여덟 응답을 받았습니다.
초기 원문 유지 비교에서 한국어 편집 참고 문서가 빠져 두 조건을 보충 실행했으며, 전체 응답은 열 개입니다.
참고 문서를 포함한 재확인에서도 원문을 그대로 유지했습니다. 실행 모델은 도구를 사용하지 않았습니다.
설치된 스킬의 자동 발견을 검증한 실험은 아닙니다.

| 과제 | 관찰 결과 |
| --- | --- |
| 주어진 경험과 한계로 글 작성 | 양쪽 모두 사실과 한계를 유지했습니다. 후보는 배경 설명을 더 적은 문단으로 묶었지만, 차이는 작았으며 더 나은 글이라는 증거로 보기는 어렵습니다. |
| 평균 결과를 전체로 일반화한 주장과 반복 결론 검토 | 양쪽 모두 핵심 근거 오류를 찾았습니다. 후보는 반복된 결론을 경미한 흐름 문제로 추가 지적했으며, 어느 쪽도 근거 없는 전면 수정을 요구하지 않았습니다. |
| 이미 적절한 짧은 안내문 검토 | 양쪽 모두 원문을 그대로 반환했습니다. |
| 필요한 사실이 부족한 경험담 작성 | 양쪽 모두 실패·측정값·교훈을 만들어 내지 않고 누락된 자료를 물었습니다. |

실행에는 비공개 한국어 작업 자료가 포함되었습니다. 같은 폴더의 재사용 시나리오는 별도로 작성한
검증용 사례이며 실행 기록의 사본이 아닙니다. 정확한 입력·출력·실행 기록은 비공개 개발 기록에 보존했습니다.
위 평가는 개발자의 정성적 관찰이며 블라인드 평가나 통계적 벤치마크가 아닙니다.

유지하기로 한 조건부 지침은 `0.15.0`에 반영합니다. 이 실험만으로 일반적인 글 품질 향상, 실행 속도
향상, 런타임 지원 확대를 주장하지 않습니다. 성숙도는 Beta를 유지하며, 비교 당시 공개 버전과 설치
핀은 `0.14.1`이었습니다.
