# Presentation Projection Example Source

This directory contains the one verified canonical SVG/PNG pair used by the public gallery to compare the three
bundled presentation surfaces. The projection outputs and their receipts live under `gallery/presentation/`.

The canonical pair remains the authority. Every gallery projection is an explicit opt-in derived sibling and is
re-verified with `scripts/projection.mjs verify`; none of the projection PNGs replaces or modifies these files.
