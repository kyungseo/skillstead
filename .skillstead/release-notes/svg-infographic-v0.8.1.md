## svg-infographic 0.8.1

This release adds examples for both naming `svg-infographic` and asking naturally for an editable technical SVG
with a verified 2× PNG. The examples still require confirmation of the output path and visual defaults before
files are created, followed by the existing render checks.

Repository-only examples keep infographic creation separate from optional prose editing when a request needs
both. Runtime support and platform evidence remain unchanged.
