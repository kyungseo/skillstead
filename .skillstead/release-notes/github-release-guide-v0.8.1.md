## github-release-guide 0.8.1

This release adds examples for both naming `github-release-guide` and asking naturally about a first public
release or a later version release. A natural-language request can start the workflow, but it does not approve
changes to files, settings, tags, visibility, or GitHub Releases.

Repository-only examples cover requests that also involve claim checking or prose work. The existing read-only
Assess step and approval-gated Guided flow remain unchanged.
